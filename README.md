# 自动退群插件

## 介绍

群成员少于配置值时自动退群，违禁词自动退群，被禁言自动退群，白名单群聊违禁词管理，并支持机器人群邀请审核。

## 安装方式

```bash
# 进入 Yunzai 插件目录
cd Yunzai/plugins

# 克隆插件
git clone https://github.com/mmr233/auto-leave-plugin.git

# 安装依赖（可选，更新时会自动安装）
cd auto-leave-plugin && pnpm install
```

## 依赖要求

- Yunzai V3
- yaml (已内置)

## 配置说明

插件支持通过锅巴面板进行可视化配置，也可直接编辑配置文件：

### 基础配置
- `minMemberCount`: 最低群成员数量，低于此数量自动退群（默认：50）
- `bannedWordTriggerLimit`: 违禁词触发次数限制（默认：3）
- `muteCountLimit`: 禁言次数限制（默认：2）

### 白名单群管理配置
- `whitelistManagement.enabled`: 启用白名单群管理功能
- `whitelistManagement.bannedWordMuteTrigger`: 违禁词触发禁言次数
- `whitelistManagement.muteLimitBeforeKick`: 踢出前禁言次数
- `whitelistManagement.baseMuteDuration`: 基础禁言时长（分钟）

### 群邀请审核配置
- `inviteManagement.enabled`: 启用机器人群邀请审核
- `inviteManagement.reviewMode`: 审核模式，0 自动同意、1 关闭不处理、2 人工审核、3 自动拒绝、4 入群后审核（默认保持人工审核）
- `inviteManagement.notifyGroups`: 审核通知群
- `inviteManagement.notifyUsers`: 审核通知用户，锅巴中可从好友列表选择
- `inviteManagement.allowInviterConfirm`: 是否允许邀请者自行确认，包括入群后的留群审核；默认开启，如需独立审核请关闭
- `inviteManagement.notifyInviterOnExpiry`: 邀请审核或留群审核到期后私聊邀请者结束通知，默认开启；入群前审核到期不会主动拒绝 QQ 邀请
- `inviteManagement.stayReviewMinutes`: 入群后审核及低人数群留群审核的时效，默认 10 分钟
- `inviteManagement.stayReviewCooldownMinutes`: 留群审核超时或拒绝退群后的冷却，默认 10 分钟，0 为关闭；按机器人和群号分别保存
- `inviteManagement.blackGroups`: 邀请黑名单群
- `inviteManagement.whiteGroups`: 邀请白名单群，会自动同意邀请，并在白名单判断中生效
- `inviteManagement.approvedGroups`: 兼容旧版的一次性放行列表；新批准状态会按 Bot 隔离并自动过期
- `inviteManagement.precheckMemberCount`: 是否在同意普通邀请前检查群成员数量
- `inviteManagement.precheckMode`: 预检查模式，`reject` 判定低于最低人数为失败，`warn` 仅提示
- `inviteManagement.excludeBotFromPrecheck`: 邀请前人数预检查是否排除本次受邀机器人（默认排除）；关闭后按现有人数加 1 比较，不排除群内其他机器人
- `inviteManagement.precheckFailureAction`: 预检查失败时转人工、直接拒绝或继续普通规则
- `inviteManagement.notifyMasterOnPrecheckReject`: 预检查失败时是否私聊通知主人

### 群管配置
- `groupAdmin.enabled`: 启用群管命令、群违禁词、投票、申请通知和群公告，默认关闭，避免和其他群管插件冲突
- `groupAdmin.commandsEnabled`: 启用基础群管命令
- `groupAdmin.bannedWordsEnabled`: 启用群级违禁词
- `groupAdmin.voteEnabled`: 启用群投票
- `groupAdmin.verifyEnabled`: 启用入群验证；需同时开启 `groupAdmin.enabled`，并将群号加入 `groupAdmin.groupVerify.openGroup`
- `groupAdmin.groupVerify.autoBlacklistOnFailure`: 连续用尽答题机会后自动加入本群验证黑名单，默认开启
- `groupAdmin.groupVerify.failedJoinLimit`: 连续失败的入群次数阈值，默认 3 次；答对清零，超时不计数
- `groupAdmin.noticeEnabled`: 加群申请通知总开关；还需在 `openGroup` 选择群聊
- `groupAdmin.groupAddNotice.openGroup`: 仅在所选群收到加群申请时通知该群本身，不会将其他群的申请转发到所选群
- `groupAdmin.groupAddNotice.skipVerifyGroups`: 人工同意后跳过一次入群验证的群聊，必须先开启对应群的加群申请通知
- `groupAdmin.announceEnabled`: 启用群公告命令
- `groupAdmin.scheduledMuteEnabled`: 启用定时禁言任务
- `groupAdmin.blacklistRequestRejectEnabled`: 启用黑名单用户申请入群时自动拒绝，仅在白名单群聊和黑名单自动踢出开启时生效

## 功能说明

### 自动退群触发条件
1. **群成员不足**：群成员数量低于配置的最小值
2. **违禁词触发**：用户艾特机器人发送违禁词达到次数限制
3. **被禁言**：机器人被禁言达到次数限制
4. **黑名单群**：机器人被拉入黑名单群聊
5. **邀请黑名单群**：机器人收到黑名单群邀请时会直接拒绝

### 机器人群邀请审核
机器人收到群邀请时，会先按黑名单、白名单顺序处理，再按配置进行人数预检查和自动同意、自动拒绝、关闭不处理或人工审核。人工审核通知显示目标群当前人数，处理人可引用通知发送 `t确认加群` / `t拒绝加群`，也可发送 `t确认加群 群号` / `t拒绝加群 群号`。预检查失败转人工时，机器人尚未进群；批准状态会在进群事件中消费，跳过本次人数退群。机器人直接进入低人数群时，会发送留群审核通知，沿用相同命令：同意留群，拒绝立即退群；超过 `stayReviewMinutes` 仍未同意则退群。若同一次邀请已发出审核通知后机器人被直接拉入群，原邀请会转为留群审核，保留同一请求 ID 和可引用的通知，不再发送第二条审核通知；为避免改变已通知的时效，仍沿用原邀请的截止时间。批准或拒绝后会清理关联的旧邀请和定时器，并通知邀请者。插件会定期核对协议端已处理的真实邀请；若机器人尚未入群，结束旧审核并通知邀请者，具体是同意还是拒绝以 QQ 实际状态为准。截止时间持久保存，重启后会重新检查并处理已到期的审核。未启用人工审核或没有可用通知目标时，仍按原规则退群。

私聊邀请卡片中的群名会用于补充同一机器人、同一发送者和同一群号的邀请信息。如果协议端没有及时上报邀请事件，插件会尝试通过 `get_group_system_msg` 查找同一群、目标为当前机器人且未处理的真实邀请，并使用其 `flag` 恢复正常审核；支持 SnowLuma 的请求列表格式。卡片由他人转发时也可匹配卡片中的原邀请人，但转发者不会因此获得邀请人的审核权限。找不到唯一匹配时会私聊说明，不会凭卡片伪造请求或自动加群。卡片不一定包含群人数，插件会尝试群信息和协议端支持的群详情接口；无法获取时显示“未知”，并按预检查失败配置处理，不能仅凭群号保证查到人数。引用已过期的邀请不会处理其他群的审核，需重新邀请；命令指定了群号或请求 ID 时，以指定目标为准。

升级时，如果机器人已在群内，而旧版遗留邀请没有关联的留群审核且无法判断是否已批准，插件会结束这条历史邀请并通知邀请者，不会仅凭该记录自动退群。

选择“入群后审核”后，普通群邀请会先同意，机器人直接被拉入群也会进入同一留群审核；入群前人数预检查不再拦截，通知展示入群后人数及是否排除本机器人的对比人数，人数未知不会当成 0。主人、通知用户、审核群管理或配置允许的邀请者可使用 `t确认加群` 留群，`t拒绝加群` 则退群。黑名单仍优先拒绝或退群，白名单跳过审核。审核截止时间和冷却期持久化；重启后等待机器人和群列表就绪再处理，退群失败会重试。通知发送失败时保留审核并重试，过期仍会退群，请先确保通知目标可用。冷却期收到邀请会拒绝，若 QQ 直接拉入则自动退出；主人可用 `t强制确认加群 群号` 清除冷却并登记一次放行。机器人完全离线期间若既未接收邀请也未收到进群事件，插件无法凭空获知该次进群。

人数接口不可用时，若邀请者或卡片发送者近期私聊发送过 `https://qm.qq.com/q/` 群分享短链，插件会尝试读取腾讯分享页并核对页面群号；链接对应其他群或页面不提供人数时不使用结果。仅靠群号或邀请卡片的 `mqqapi` 链接不能生成有效的分享短链；QQ 分享页格式和可用性也可能变化。

人工审核的机器人群邀请到期且未处理时，默认私聊邀请者本次审核已结束；可在群邀请审核设置中关闭。入群后留群审核超时并成功退群后，也会通知审核群，并按该开关决定是否私聊邀请者。待处理记录会在重启后恢复，到期通知不适用于群成员加群申请；入群前审核结束通知不代表机器人主动拒绝了 QQ 邀请。

同一机器人在同一群内对同一 QQ 连续多次入群并用尽验证答题机会时，会加入该群的验证黑名单并踢出；后续进群会再次踢出，申请入群会被拒绝。每次入群最多计一次；手动重新验证不计入入群次数。答对验证题会清零连续失败记录；超时和未完成验证的进退群不计数。群管理员可在群内使用 `t验证解黑 @用户` 解除该群的验证黑名单；此名单不会写入 Yunzai 全局用户黑名单。

邀请白名单群用于邀请阶段自动同意；生效时也会视为白名单群，进群后跳过人数检查。白名单群管理里的群聊白名单是全局白名单入口，适合长期管理不会自动退群、违禁词管理等行为。

### 群加群申请审批
开启本群加群申请通知后，机器人只把该群自己的申请发回该群，不会把其他群的申请转发进来。机器人会登记申请通知消息；群主、管理员或主人引用该通知发送 `t同意入群`，机器人会调用原申请的 `flag` 同意入群；发送 `t拒绝入群` 可拒绝申请。审批状态按 Bot、群聊和用户关联，并在处理或过期后失效。配置在 `groupAdmin.groupAddNotice.skipVerifyGroups` 中的群聊，人工同意后只跳过本次入群验证，未配置的群聊仍按正常入群验证流程处理。

### 白名单群管理
白名单群聊不受上述退群条件影响，但启用了违禁词管理功能：
- 普通用户发送违禁词会被禁言/踢出
- 管理员发送违禁词会收到特殊回复
- 支持自动踢出黑名单用户，锅巴中可从好友列表选择，也可手动填写非好友 QQ

### 群管黑名单说明
群管不再维护独立用户黑名单。`t踢黑` 和群违禁词的 `踢黑` 处理方式会写入 `T用户黑名单` 使用的同一份 Yunzai 用户黑名单，并且只对白名单群聊开放。黑名单用户入群后的自动踢出仍由白名单群管理功能处理；群管只提供可关闭的申请阶段拒绝能力。

## 常见问题

**Q: 如何让群不触发自动退群？**
A: 使用 `t拉白 群号` 将群添加到白名单。

**Q: 违禁词如何触发？**
A: 非白名单群需要艾特机器人并发送违禁词才会触发；白名单群直接发送违禁词即可触发管理操作。

**Q: 如何关闭禁言自动退群？**
A: 在锅巴面板或配置文件中将 `muteCountLimit` 设置为较大值即可。
